# Job Recommendation Backend

FastAPI + LangGraph API. See the root [README](../README.md) for setup.

From this directory (with venv active):

```bash
uv sync          # or: pip install -e .
fastapi dev      # http://127.0.0.1:8000
```

The app entrypoint is configured in `pyproject.toml` as `main:app` (see `main.py`).
